# Analytics Portfolio Dashboard

An interactive business intelligence portfolio project that pairs a synthetic retail performance dashboard with an evidence-backed skills profile.

## What it demonstrates

- KPI reporting for revenue, units, orders, and average order value
- Interactive period, category, and region filters
- Monthly trend visualization, category comparisons, and regional summaries
- An analyst note that recalculates from the selected data
- A CV-based skills profile covering Power BI, dashboard development, Power Query, ETL, data modeling, DAX, SQL, and Excel

The skills section cites only evidence present in the CV. It does not assign a seniority level or estimate years of experience.

## Data and privacy

The retail records are generated in the browser as synthetic demonstration data. They are not real business or customer data. CV references are limited to skills, certification, and project details; personal contact information and the certification credential ID are not included.

## Run locally

Open `index.html` in a browser, or serve the project folder over HTTP:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

No package installation or build step is required.
